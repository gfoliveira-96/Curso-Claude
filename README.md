# Curso Claude

Repositório de estudos e projetos práticos do curso de Claude / Claude Code — explorando o uso da IA da Anthropic para produtividade, automação e desenvolvimento de software.

## Sobre

Este repositório reúne os exercícios, anotações e projetos desenvolvidos ao longo do curso, cobrindo desde os conceitos básicos de interação com o Claude até fluxos mais avançados de automação e integração com ferramentas de desenvolvimento.
